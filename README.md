# Keyveni Dijital Menü

Keyveni için mobil uyumlu, QR kodla erişilebilen dijital menü.

## Yayınlama

GitHub Pages ayarlarından `main` dalı ve `/ (root)` klasörünü seçin.

## Özellikler
- Mobil öncelikli arayüz
- Kategori filtreleme ve ürün arama
- WhatsApp üzerinden siparişe geçiş
- PWA manifest ve servis çalışanı
- Ana ekrana eklenebilir ikonlar

Ürün fiyatları ve ürün fotoğrafları işletmeden teyit edilene kadar örnek/boş değerler olarak kalmalıdır.
